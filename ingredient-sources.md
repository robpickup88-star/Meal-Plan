# Ingredient Sources

Upload this file to your Claude Project as knowledge. It tells Claude where you
buy each ingredient and in what pack size.

- **Source** is `bulk` (goes on your next bulk order) or `store` (buy at the
  shop).
- **Pack size** is what one unit of purchase contains. Claude rounds bulk items
  up to whole packs.
- Ingredients missing from this list show up under "Not sure" so you can add
  them.

Keep ingredient names the same as in `recipes.md`.
